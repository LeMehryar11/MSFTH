GitHub Enterprise ROI challenge

Contoso: GitHub Enterprise investment case

A financially reasoned recommendation on migrating from Azure DevOps

Prepared for David Schankwirt and Johannes Starkwind · GitHub Copilot excluded from all figures

1 · Recommendation

Run a small, bounded pilot — do not commit to a full migration yet

On the numbers modelled here, none of the three scenarios pay back a full ~3,000-repository migration within 5 years — not even the upside scenario. We are therefore not recommending Contoso commit budget for a full-scope migration today.

What we are recommending: a small, tightly scoped pilot — roughly 100 users and 300 repositories (10% of the estate), GitHub Enterprise only, no Advanced Security. Its cost is a small, bounded fraction of the full migration cost (see Slide 5), and its purpose is to replace this model's assumptions with Contoso's own real figures before any larger commitment is considered.

Advanced Security is not recommended at any scale yet: Contoso's existing BlackDuck, SonarQube and in-house Dependabot equivalent already cover this need (see Slide 4). A pilot of Advanced Security, if run at all, should happen only after the GitHub Enterprise pilot, on a small set of the highest-risk repositories, measured against that existing baseline.

3 · Cost response

"This subscription is too expensive"

Yes — and the model agrees with you. GitHub Enterprise ($21/user/month) plus Advanced Security ($49/user/month) is structurally more expensive per seat than Azure DevOps ($6/user/month), at every discount tier on offer. On our own numbers, a full migration does not pay back within 5 years in any scenario we modelled.

That is exactly why we are not recommending a full commitment today. We are recommending a small, bounded pilot (, see Slide 5) — a fraction of the a full migration would cost under these same assumptions.

If the pilot's real numbers still do not support a positive case, the right decision is to stop there having spent a bounded, known amount — not to have committed to the full programme on assumptions alone.

5 · Scope, effort and timeline

A small, bounded pilot before any larger decision

MetricRecommended pilotFull migration (for comparison)
  1. Months 0–3 — Pilot. Migrate Git, Boards and Pipelines for the pilot group only. Confirm the real discount tier actually on offer. No Advanced Security in this phase.
  2. Months 3–6 — Measure. Track real migration hours per repository, real developer time impact, and the real discount tier, against the placeholder assumptions in this model.
  3. Month 6 — Decision gate. Re-run this model with the pilot's real figures. Only then decide whether a wider rollout — and at what scope — has a defensible financial case.
6 · Evidence to collect before committing further budget

Six inputs that materially change the numbers

  • A firm user-count commitment — 500 versus 1,000 users roughly doubles total spend.
  • The discount tiers Microsoft actually agrees for GitHub Enterprise and Advanced Security.
  • Contoso's current BlackDuck, SonarQube and Nexus licence spend, to value any tool retirement.
  • A confirmed EUR/USD basis, since licence pricing is quoted in dollars and the partner's migration rate in euros.
  • A real migration-effort estimate per repository from the preferred partner, replacing the planning range used here.
  • Whether Contoso will also take Microsoft's Unified Support, and its cost.
7 · Decision requested

What we are asking the executive team to approve today

  • Approve the bounded pilot only (, Slide 5) — GitHub Enterprise, no Advanced Security, for a defined pilot group.
  • Do not approve a full-scope migration or Advanced Security rollout today — the numbers do not currently support it.
  • Nominate an owner to collect the six evidence items above during the pilot, so the model can be re-run with real figures at the month-6 decision gate.
This is a recommendation to spend a small, bounded amount to find out whether a larger investment would be justified — not a recommendation to commit to the full programme today.
