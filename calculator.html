Read before using these figures externally:
  • All three scenarios now use the handout's maximum discount (30% GHE, 17% GHAS), per Contoso's confirmation that this applies regardless of scenario. Discount is therefore no longer a source of difference between scenarios — migration effort, engineer time saved, and tool retirement are.
  • Migration cost is quoted by the partner in euros (€240/hour/person); this tool combines it with dollar licence figures at an illustrative 1:1 rate — confirm the real EUR/USD rate with finance before quoting a combined number.
  • Tool-retirement savings (BlackDuck, SonarQube, Nexus) use researched, non-Contoso-specific industry-typical pricing, not Contoso's actual spend — see Quant-Report.md for sources. Confirm real figures before relying on them externally.
  • GitHub tends to port Advanced-Security-equivalent capability back into Azure DevOps within roughly 6 months of release. This is a real risk to the Base/Upside retirement case, not reflected as a number here — see Sceptic-Report.md.
  • GitHub Copilot is excluded from every figure in this tool, per the challenge's boundary condition.
  • These figures are a planning model, not a quotation. See Sceptic-Report.md, Advocate-Report.md, Neutral-Report.md and Quant-Report.md for how each editable default was arrived at.
